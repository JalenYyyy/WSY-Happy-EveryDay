# 猫咪小家产品需求文档

## 1. 产品定位

猫咪小家是一个两人共享的猫咪聊天 Web/PWA 应用，同时集成了一个基于大模型 Agent 的通用对话工作台（Pi Agent）。用户可以和多只只保留名字的猫咪聊天，也可以切换到 Agent 模式与具备文件读写和命令执行能力的 AI 进行工程类对话。猫咪聊天背后通过 OpenAI 兼容接口接入大模型，Agent 使用相同的模型配置。

第一版目标不是做开放社区，而是做一个私密、轻量、可长期陪伴的小家空间，并为两位用户提供便捷的本地 AI 助手入口。

## 2. 目标用户

- 两位固定用户，共享同一批猫咪。
- 两位用户可以看到同一份猫咪列表和聊天记录。
- 后续可扩展为多用户家庭、情侣、朋友空间。

## 3. 核心使用场景

- 用户登录后选择一只猫咪进入聊天。
- 用户和猫咪进行微信式私聊，但聊天记录对两位用户共享。
- 用户创建新猫咪时只填写名字。
- 用户编辑猫咪时只修改名字。
- 用户删除不需要的猫咪，但删除必须防误触。

## 4. MVP 功能范围

### 已实现功能

- 两个预设账号登录：
  - `月 / cat123`
  - `泽 / cat123`
- 每个用户当前保留名字与密码能力，并允许设置一个供所有猫咪通用的称呼：
  - 名字
  - 登录密码
  - 忘记密码恢复码（登录后生成，登录页可用来重置密码）
  - 管理员协助重置密码（服务端配置管理员密码后，登录页可在忘记密码弹窗中使用）
  - 在个人资料里设置“猫咪们怎么叫我”，默认留空
- 5 只默认猫咪：
  - 耐耐
  - 咪仔
  - 布丁
  - 丢丢
  - 希乐乐
- 共享猫咪列表和共享聊天记录。
- 微信式聊天界面。
- 每只猫拥有独立的电子相册：发给猫咪的图片会自动按时间倒序收录，展示上突出照片本身，只保留时间信息，并支持沉浸式大图预览。
- OpenAI 兼容大模型接口。
- 大模型未配置或失败时，本地备用回复。
- 创建猫咪：
  - 名字
  - 创建完成后直接回到聊天界面
- 编辑猫咪：
  - 名字
  - 性格
  - 回复方式
  - 补充设定
- 删除猫咪：
  - 位于危险操作区
  - 必须输入猫咪当前名称确认
  - 输入前后空格会自动忽略
  - 禁止删除到一只猫都不剩
  - 删除时同步清理聊天记录和历史设定残留
- PWA manifest 基础配置。
- Pi Agent 对话界面（`/agent`）：
  - ChatGPT 风格暗色 UI，侧边栏多会话管理。
  - 消息流式渲染（SSE）。
  - 内置工具：读取文件、写入文件、执行 Shell 命令。
  - 工具执行阶段展示简洁的“处理思路”摘要，不直接向用户暴露命令参数和原始输出。
  - 严格按用户要求执行；未明确要求时，不默认生成 Word 或其他可下载文件。
  - 如果需求、输出格式或范围不清楚，先向用户澄清，再执行工具或生成结果。
  - 上传文件和生成文件按会话暂存并自动清理，避免长期堆积。
  - 停止生成（abort）按钮。
  - 与猫咪聊天主界面通过 Bot 图标按钮互通。
  - 需要登录，未登录跳转 `/login`。

### 暂不包含

- 开放注册。
- 多空间、多家庭。
- 真实权限管理后台。
- 猫咪聊天流式输出。
- 语音消息。
- 云对象存储。
- 多供应商可视化配置后台。
- 邮箱 / 短信找回密码。
- Pi Agent 会话持久化（当前重启丢失）。
- Pi Agent 工具白名单与细粒度权限控制。
- Pi Agent Markdown 渲染与代码高亮。
- Pi Agent 移动端适配。

## 5. 关键体验要求

- 界面风格偏苹果风，淡色、简洁、柔和。
- 聊天区域参考微信，消息紧凑、易扫读。
- 创建猫咪不能因取消而产生空白猫咪。
- 创建时只填写名字，确认后直接进入聊天。
- 删除猫咪必须刻意、明确、可防误触。
- 模型不可用时不能让用户以为应用坏掉，要给出温和备用回复和提示。

## 6. 验收标准

- 两个默认用户都能登录。
- 登录页应展示当前数据库中的用户名称，而不是写死账号按钮。
- 用户登录后可以生成恢复码；忘记密码时可在登录页用恢复码重置密码。
- 默认 5 只猫咪展示正常。
- 用户 1 发送消息后，用户 2 能看到同一条聊天记录。
- 猫咪回复上下文只基于猫咪名字、当前用户名字与最近聊天记录。
- 创建猫咪取消时，列表不新增猫咪。
- 创建猫咪确认后，新猫咪直接进入聊天界面。
- 删除猫咪输入错误名称时不会删除。
- 删除猫咪输入正确名称时才删除。
- 未配置大模型时，聊天仍可得到备用回复。
- 登录后访问 `/agent`，可以新建会话、发送消息，并流式接收 Agent 回复。
- 进入任意猫咪的电子相册后，可以看到按时间倒序排列的照片墙；列表与预览都以照片为主，只保留时间信息，并支持逐张浏览。
- 未登录时访问 `/agent` 应跳转登录页。
